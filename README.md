# SocksForward

一个带 Web 管理界面的端口转发工具：将本机/服务器上的 TCP/UDP 监听端口转发到目标地址，并通过指定的 SOCKS5 节点作为出口连接目标。

## 功能

- Web 管理页面：添加/编辑/删除 SOCKS5 节点与转发规则
- 支持协议：TCP / UDP / TCP+UDP（both）
- 配置热更新：在 Web 页面修改后自动写入配置文件并立即生效
- 管理密码：首次初始化写入密码哈希，后续可在页面内修改

## 快速开始

### 1) 运行

在项目根目录执行：

```bash
go run . -port 8080 -config config.json -password 123456
```

首次运行时，如果配置文件不存在（或为空），程序会创建 `config.json`，并用 `-password` 指定的默认密码初始化 Web 管理密码。

### 2) 打开 Web 管理页

浏览器访问：

```
http://localhost:8080/
```

使用首次初始化时的密码登录。

### 3) 添加 SOCKS5 节点与转发规则

- 先在「SOCKS5 节点」里新增一个节点（填写 `host:port`，可选用户名/密码）
- 再在「转发规则」里新增规则：
  - 协议：TCP / UDP / Both
  - 监听地址：例如 `:8080`、`0.0.0.0:5353`
  - 目标地址：例如 `1.1.1.1:443`、`8.8.8.8:53`
  - 出口节点：选择刚创建的 SOCKS5 节点
  - 勾选「立即启用」后会立刻开始监听并转发

## 启动参数

- `-port`：Web 管理端口（默认 `8080`）
- `-config`：配置文件路径（默认 `config.json`）
- `-password`：默认 Web 管理密码（默认 `123456`，仅在首次初始化配置时生效）

说明：

- 当配置文件中已存在 `web.passwordSaltB64` 与 `web.passwordSha256B64` 时，`-password` 不会覆盖现有密码。
- 想要修改密码，请在 Web 页面底部「修改密码」操作。

## 转发行为说明

- TCP：监听 `listen`，每个新连接都会通过 SOCKS5 节点建立到 `target` 的 TCP 连接，并进行双向转发
- UDP：监听 `listen`，按客户端地址维护会话；通过 SOCKS5 的 UDP ASSOCIATE 进行转发，会话 2 分钟不活跃会清理
- Both：同时开启 TCP 与 UDP 两种监听

## 安全建议

- Web 管理界面未内置 HTTPS 与访问控制（除密码外），不要直接暴露到公网；推荐放在内网或通过反向代理加 TLS 与访问限制
- 首次运行后请尽快在页面中修改默认密码

## 常见问题

- 规则显示「启动失败」：说明监听失败或 SOCKS5 节点不可用/不可达，可检查节点地址、认证信息、端口占用以及目标地址格式
- 目标地址必须是 `host:port`：例如 `example.com:80`、`1.2.3.4:443`，不支持仅写域名或仅写端口
